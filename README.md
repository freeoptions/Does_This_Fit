# Does This Fit?（这合适吗）

用于在固定桌面模板中快速判断壁纸是否保留的 Android 工具。

## 当前实现

- Kotlin + Jetpack Compose + Room + Coil。
- 应用内固定 `1080 × 2400` 桌面模板，只替换壁纸背景。
- 支持普通模式和沉浸式全屏预览。
- 支持固定多个图片文件夹，并配置是否递归扫描子文件夹。
- 先标记待删图片，确认后统一移动到配置的待删文件夹。
- 移动失败时使用复制校验回退，不在失败时删除源文件。
- 支持只导出配置的 JSON 文件。

## 使用前提

这是自用侧载工具，首次使用需要在系统设置中允许“管理所有文件”。

## 重要说明

桌面模板当前使用 Compose 固定布局绘制。后续如需逐像素贴合参考图，可以继续替换图标素材和坐标，不影响图片扫描、标记、移动和配置逻辑。
